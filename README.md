# ✒️ Kertas & Pena — Web Toko Alat Tulis Modern

Aplikasi web e-commerce toko alat tulis (*stationery*) responsif yang dibangun menggunakan **HTML5**, **CSS3**, dan **Vanilla JavaScript** tanpa memerlukan *framework* atau instalasi server tambahan.

## ✨ Fitur Utama
- **Katalog Produk Interaktif**: Menampilkan daftar alat tulis lengkap dengan harga Rupiah, kategori, pencarian *real-time*, dan pengurutan harga.
- **Keranjang Belanja (Cart Drawer)**: Tambah produk, ubah jumlah (`+`/`-`), perhitungan otomatis subtotal, dan gratis ongkos kirim untuk belanja minimal Rp150.000.
- **Autentikasi Pengguna (Login & Daftar)**: Dilengkapi tombol *Login Instan Demo* serta penyimpanan sesi menggunakan `localStorage`.
- **Checkout & Riwayat Pesanan**: Formulir alamat pengiriman, pilihan metode pembayaran, dan halaman riwayat transaksi pengguna.

## 🚀 Cara Menjalankan Proyek
1. Pastikan keempat file (`index.html`, `style.css`, `script.js`, dan `README.md`) berada dalam satu folder yang sama.
2. Klik dua kali file `index.html` untuk membukanya langsung di browser (Chrome, Edge, Firefox, atau Safari).
3. *(Opsional)* Jika menggunakan **VS Code**, klik kanan pada `index.html` dan pilih **Open with Live Server**.

## 🛠️ Teknologi yang Digunakan
- **HTML5** (Struktur Semantik)
- **CSS3** (CSS Variables, Flexbox, CSS Grid, Responsive Media Queries)
- **JavaScript ES6+** (DOM Manipulation & Web `localStorage` API)
